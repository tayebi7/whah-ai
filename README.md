# Waha AI 🤖

تطبيق Android للذكاء الاصطناعي - محادثة ذكية مع دعم مزودين متعددين.

## تحميل APK
1. اذهب إلى تبويب **Actions**
2. اضغط على آخر عملية بناء ناجحة ✅
3. انزل إلى **Artifacts**
4. حمّل **waha-ai-debug**

## الإعداد
1. ثبّت الـ APK على هاتفك
2. افتح التطبيق
3. اضغط ⚙️
4. أدخل Base URL + API Key + Model
5. ابدأ المحادثة!
