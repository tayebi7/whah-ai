# Waha AI 🤖

منصة ذكاء اصطناعي متكاملة تدعم المحادثة، توليد الصور، تحليل المستندات، وبرمجة التطبيقات.

## المميزات

- 💬 محادثة ذكية مع دعم بث الردود
- 🌙 الوضع الداكن والفاتح
- 🌍 دعم العربية (RTL) والإنجليزية والفرنسية
- 🔌 دعم مزودين متعددين (OpenAI, Anthropic, Google, Groq, ...)
- 📄 تحليل المستندات والصور
- 💻 مساعد برمجة متقدم
- 🎨 توليد الصور (يتطلب مزود يدعم ذلك)
- 📱 تصميم متجاوب للهاتف والحاسوب

## التشغيل محليًا

### المتطلبات
- Node.js 20 أو أحدث
- npm

### الخطوات
```bash
# 1. استنساخ المستودع
git clone https://github.com/tayebi7/whah-ai.git
cd whah-ai

# 2. نسخ ملف البيئة
cp .env.example .env.local

# 3. تعديل .env.local وإضافة مفاتيح API

# 4. تثبيت الاعتمادات
npm install

# 5. تشغيل التطبيق
npm run dev
