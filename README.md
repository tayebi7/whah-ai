# Waha AI — واحة

مساحة عمل ذكية: دردشة، استوديو صور وفيديو، تحويل مستندات، وتأليف كتب، مع مزوّدي ذكاء اصطناعي تضيفهم بنفسك.
Next.js 15 · React 19 · TypeScript · واجهة عربية/إنجليزية/فرنسية (RTL) · وضع داكن · مناسبة للجوال.

## الميزات
- **الدردشة**: بث مباشر، تبديل تلقائي بين المزوّدين عند الفشل، إرفاق ملفات وصور، التقاط صورة/مسح مستند بالكاميرا وفهمها (رؤية + OCR)، تصدير المحادثة.
- **الاستوديو**: توليد صور من وصف؛ تحويل الصور إلى فيديو (عرض شرائح)؛ **فيديو منتج** (صورك + صور ذكاء اصطناعي + تعليقات مولَّدة)؛ فيديو من مزوّد يدعم واجهة فيديو غير متزامنة (مسارات وحقول قابلة للضبط).
- **الملفات**: رفع (سحب وإفلات)، معاينة، تنزيل، استخراج النص، سؤال الذكاء الاصطناعي عن الملف، **تحويل الصيغ** (DOCX/PDF/EPUB/MD/TXT/HTML/صور/صوت/فيديو).
- **الكتب والقصص**: خطة ثم فصول بالذكاء الاصطناعي، وتصدير DOCX / PDF / EPUB / MD.
- **الإعدادات**: إضافة مزوّدين يدوياً (OpenAI، Anthropic، Gemini، OpenRouter، Groq، NVIDIA، Mistral، DeepSeek، Together، Cohere، HuggingFace، Ollama، LM Studio، أو أي نقطة متوافقة مثل AMD)، اختبار، ترتيب الأولوية، تفعيل/تعطيل، منع إرسال الملفات لمزوّد معيّن. المفاتيح تُحفظ مشفّرة.

## التشغيل
```bash
npm install
cp .env.example .env.local   # اختياري
npm run dev                  # http://localhost:3000
npm test                     # 51 اختبارًا (وحدات + تكامل على معالجات المسارات الحقيقية)
npm run build && npm start
```
**أدوات النظام المطلوبة** (للتحويل والفيديو والكتب وOCR): `ffmpeg`, `pandoc`, `libreoffice`, `poppler-utils`, `tesseract-ocr` (+ `tesseract-ocr-ara` للعربية). على Ubuntu:
`sudo apt install ffmpeg pandoc libreoffice-writer libreoffice-calc poppler-utils tesseract-ocr tesseract-ocr-ara fonts-noto-core`

## الإعدادات البيئية
انظر `.env.example`: `WAHA_ACCESS_TOKEN`, `WAHA_ENCRYPTION_KEY`, `WAHA_DATA_DIR`, `WAHA_ALLOW_LOCAL`, `WAHA_MAX_UPLOAD_MB`, `WAHA_MAX_GENERATED_MB`, `WAHA_RETENTION_DAYS`, `WAHA_FONT_FILE`, `WAHA_PROVIDERS`.

## الحالة والحدود (بصراحة)
**تم التحقق منه** في بيئة التطوير: اختبارات الخلفية (51/51) واختبار متصفح شامل (Playwright، 41 خطوة) على جميع التبويبات مقابل المعالجات الحقيقية ومزوّد وهمي، بما فيها الجوال والعربية RTL والوضع الداكن.

**لم يُتحقق منه**: `next build` وفحص أنواع `tsc` لملفات JSX (لم يكن تنزيل الحزم متاحاً)، والتجربة مع مزوّدين حقيقيين. شغّل `npm run typecheck && npm run build` أول مرة وأصلح أي ملاحظة بسيطة.

**قيود معروفة**
- لا حسابات مستخدمين ولا قاعدة بيانات: رمز وصول مشترك واحد، وتخزين ملفات JSON على نسخة واحدة (لا يصلح للتوسع الأفقي).
- توليد الصور عبر نقاط متوافقة مع OpenAI فقط (ليس Anthropic/Gemini الأصلية).
- حماية SSRF تفحص اسم المضيف فقط (بلا تثبيت DNS)؛ للنشر العام قيّد الخروج على مستوى الشبكة.
- جودة الفيديو من المزوّد تعتمد على واجهة المزوّد وإعدادات المسارات التي تدخلها.
